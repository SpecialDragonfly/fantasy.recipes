Silkscreen
==========

silkscreen-400.woff2 / silkscreen-700.woff2

Pixel display face used for the landing-page wordmark and card labels
(templates/home.twig, .landing-* rules in public/css/site.css). Self-hosted
rather than loaded from a CDN so the site stays offline-capable on the Pi
(see architecture.md -- Stack Overview).
